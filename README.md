# About Me

B.Tech ECE student at **IIIT Delhi**.

Most of my time is spent somewhere between
writing code, debugging code, and wondering why the code that worked yesterday refuses to cooperate today.

I enjoy building systems from the ground up — whether that’s **ML tools, backend platforms, or low-level architecture projects**.

My typical workflow looks something like:

1. build something interesting
2. break it accidentally
3. debug it for several hours
4. finally understand why it broke
5. pretend that was the plan all along

Areas I enjoy working in:

* machine learning
* systems and architecture
* full stack engineering

Outside programming I follow **Formula 1, cricket, football, and competitive games like Valorant and CS2**.

Currently exploring deeper topics in:

* model optimization
* distributed systems
* quantitative finance tooling

And yes — **actively looking for internships where I can build real systems and learn from people smarter than me.**
